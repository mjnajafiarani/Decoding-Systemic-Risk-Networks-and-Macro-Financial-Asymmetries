\section*{Code and Data Availability}

The code used for the nested temporal validation, construction of the predictive-attribution network $W$, construction of the model-implied response network $R$, grouped ablation analyses, and first-difference sensitivity analysis is publicly available at
\url{https://github.com/mjnajafiarani/Decoding-Systemic-Risk-Networks-and-Macro-Financial-Asymmetries}.
The repository contains the audited analysis pipeline, runnable scripts, and the derived result tables used in the manuscript.

The underlying macro-financial series were obtained from the sources documented in Supplementary Appendix A. Because source-specific redistribution conditions may apply, the compiled analysis workbook is not redistributed in the repository. Supplementary Appendix A also documents the candidate-network specification and the literature basis for the admissible directed relationships.
